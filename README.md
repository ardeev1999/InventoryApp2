# Inventory App

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Мобильное приложение для инвентаризации техники и мебели. 
Позволяет импортировать данные из Excel, сканировать QR-коды и штрих-коды, отслеживать статус предметов.

## Функциональность
- Импорт из .xlsx, .xls, .csv в SQLite.
- Просмотр списка предметов с фильтрацией по статусу (найден/отсутствует).
- Сканирование QR-кодов и штрих-кодов через камеру.
- Автоматическое изменение статуса при совпадении инвентарного номера.
- Отдельный список найденных предметов.

## Технологии
- Kotlin
- SQLite
- Библиотеки для работы с Excel (например, Apache POI)
- Камера и сканирование: ZXing Android Embedded 4.3.0

## Сканирование и инвентарные номера

Сканер настроен на QR, Data Matrix, Aztec, PDF417, MaxiCode, Code 128,
Code 39, Code 93, Codabar, ITF, EAN-8/13, UPC-A/E и GS1 DataBar (RSS).
Это форматы декодеров ZXing, а не гарантия чтения любого существующего
штрихкода или повреждённой этикетки; MaxiCode особенно требователен к изображению.
Для ITF дополнительно разрешены короткие номера из 2 и 4 цифр.

Результат передаётся в поиск как строка без дополнения цифрами, удаления
ведущих нулей, обрезки пробелов или преобразования в число: `1234`, `0012`
и `001234` — разные номера. Поиск в Room выполняется по точному совпадению.
Служебные символы формата обрабатывает декодер по правилам соответствующего стандарта.

Если генератор этикетки уже дополнил номер нулями или контрольной цифрой,
сканер не может восстановить исходный короткий номер без отдельного правила.
EAN/UPC имеют фиксированную длину; для произвольного четырёхсимвольного номера
используйте Code 128 или QR. ITF допускает только чётное количество цифр.
В импортируемом Excel храните номера как текст: числовые ячейки могут терять
ведущие нули ещё до сканирования.

### Проверка изменений

`bash gradlew :app:testDebugUnitTest` проверяет декодирование сгенерированных
изображений: короткие номера, ведущие нули, текст, пробелы, EAN/UPC и Codabar.
На телефоне дополнительно проверьте разрешение камеры, отмену сканирования,
поиск существующего номера и сообщение для отсутствующего. Импортируйте
`1234`, `0012` и `001234` как три отдельных предмета и убедитесь, что сканирование
каждой этикетки отмечает только соответствующий предмет.
